# Phishing Pipeline Coverage Audit

Scope: this audit covers the live `hash_only` path used by the controller: Stage 1 in `phishing_pipeline/comparison.py`, Stage 2 / final labeling in `phishing_pipeline/pipeline.py`, and brand / TVC alias handling in `phishing_pipeline/utils.py`. Dormant helpers are not counted as implemented unless they materially affect this live path.

Active live defaults referenced below:

- `comparison.DEFAULT_HASHING_THRESHOLD = 65.0`
- `comparison.DEFAULT_DOMAIN_SIMILARITY_THRESHOLD = 0.85`
- `comparison.DEFAULT_HIGH_CONFIDENCE_THRESHOLD = 78.0`
- `comparison.DEFAULT_MEDIUM_CONFIDENCE_THRESHOLD = 68.0`
- `comparison.DEFAULT_TYPO_TOP_K = 10`
- `comparison.DEFAULT_TYPO_MIN_SCORE = 0.45`
- `comparison.DEFAULT_LEXICAL_PASS_MIN_SCORE = 0.85`
- `comparison.DEFAULT_CLIP_MARGIN_MIN = 0.12`
- `comparison.DEFAULT_CLIP_STRONG_SIMILARITY = 0.92`
- `comparison.DEFAULT_SCORING_WEIGHTS = {domain: 30.0, screenshot: 20.0, favicon: 14.0, ssl_hash: 12.0, html_hash: 6.0, domain_hash: 8.0, keywords: 10.0}`
